# Reference study — Kree8 Studio

Inspected on 19 October 2026: the live home page from hero to footer, project gallery, playground, contact page, pricing components on the home page, and the mobile home layout. Browser inspection included DOM structure, scroll containers, computed typography, and animation state.

## Observed structure

The desktop shell has an approximately 320px fixed navigation rail. The page content scrolls in its own right-hand container. A light neutral page sheet has large rounded corners and begins below the viewport's top edge. The sidebar includes a wordmark, icon-and-label navigation, a raised active pill with an arrow, contact actions, and a bottom proof area.

The home page alternates a roughly 660px text column with roughly 860px visual sections. Its opening combines a small availability/proof line, a large tightly spaced sans-serif headline with an inline dimensional object, and pill actions. A wide showreel appears beneath it.

The long home narrative moves through a problem, a solution, visual brand explorations, an interactive typography tool, a wide work showcase and service categories, pricing, testimonials, team, a closing note, and a final CTA. The page changes scale between quiet text and rich visual artifacts instead of using one repeated grid.

Project navigation uses rounded category controls above generously sized stacked visual showcases. The playground uses a collapsed icon rail and a spatial image canvas. The contact flow is a separate centered panel over a colored background. On mobile the sidebar becomes a top logo/menu header, the page canvas narrows, and controls stack when necessary.

## Observed motion and material

- Soft multi-layer shadows on white controls, pill navigation, and rounded media frames.
- Raised active tabs, small directional arrows, and subtle hover movement.
- Animated inline objects and an interactive typography sample.
- A controlled video showreel, animated transitions, an image canvas, and repeating team imagery.
- Static text remains part of a paced editorial composition.

## Portfolio adaptation

| Reference element | Portfolio implementation |
| --- | --- |
| Fixed navigation rail | Home, Projects, Playground, My toolkit, About me; contact, resume, and social actions |
| Rounded scrollable page | Same desktop shell and independent content scroll; compact mobile header and drawer |
| Editorial hero and inline object | Bhoomika's exact identity and tagline, with a small code tile |
| Wide showreel | A layered design/development showcase with a one-shot entrance and replay control |
| Narrow narrative / wide work | Personal introduction, a seven-project manual carousel, and work-category links |
| Category gallery | Filter controls above full-width project covers, with details and original links |
| Playground canvas | Three bounded interactions: saved-state button, adjustable type, and a motion study |
| Pricing / agency proof | Real skills, experience, education, and achievements; no invented clients or metrics |
| Team / closing note | Supplied About content, a personal sign-off, and Connect |
| Contact intake flow | Direct email, copy-email control, resume, GitHub, and LinkedIn |

The user's requirement for a lightweight playground takes precedence over the reference's continuous canvas. No auto-advancing project carousel, infinite feed, autoplay video, or repeating playground animation is included. The reference's logo, client work, portraits, photography, and agency claims are not used as Bhoomika's work.

The portfolio uses original code-drawn interface studies based on the supplied project descriptions. Project detail pages explicitly identify these previews as illustrative and link to the repositories, Figma concept, or live demo.
